# Tidepool Tiles

A triple tile-match puzzle set on the Maine coast. Tap tiles to move them into the tray, match three of a kind to clear them, and empty the board before the 7-slot tray fills up.

- 24 tile pictures, from lobsters and lighthouses to blueberries and puffins
- 400 hand-checked levels (every one has a solution), then endless generated levels
- Boosters: Undo, Pop 3 and Shuffle

`index.html` is the complete game (one file, CrazyGames HTML5 SDK v3). `covers/` and `videos/` hold the store art.
